# Looponics — Technical Capabilities

## Frontend & Full-Stack Capabilities
- Next.js 16 App Router, Turbopack, React Server Components, Server Actions
- TypeScript (Strict Mode) across all packages
- Responsive styling: CSS Modules, Tailwind CSS, Motion/GSAP animations
- State management and data synchronization

## Backend & API Engineering
- Serverless API architecture (Node.js/TypeScript on Vercel)
- RESTful endpoints and Server-Sent Events (SSE) streaming
- Webhook consumers with cryptographic signature validation
- Error sanitization envelopes and strict origin validation

## Database & Vector Storage
- PostgreSQL with Supabase
- pgvector semantic embedding retrieval (HNSW cosine similarity indexing)
- Declarative SQL migrations checked into version control
- Row-Level Security (RLS) policies

## Artificial Intelligence & LLMs
- Vercel AI SDK integration (Google Gemini, Groq)
- Structured tool-calling with server-side allowlisting
- Knowledge retrieval-augmented generation (RAG) with source attribution
- Evaluation and regression benchmarking
